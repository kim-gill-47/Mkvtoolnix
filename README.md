## 📖 About

MKVToolNix is an open source toolkit maintained by Moritz Bunkus and the wider Matroska community. It focuses on the Matroska container format: merging multiple audio, video and subtitle tracks into a single MKV, splitting files by size or timestamp, extracting individual streams, and editing track properties without re-encoding. Recent builds ship an updated mkvmerge engine, improved HEVC and AV1 handling, refreshed GUI themes and continued MKV/WebM spec compliance.

If you came looking for a MKVToolNix download for Windows 10 or 11, this page lists the current system requirements, install steps and common troubleshooting fixes. The repository is a community reference page and hosts no binaries itself.

**Good for:** video archivists · subtitle muxers · anime and TV collectors · Blu-ray rippers · podcast and stream editors · power users managing large MKV libraries · anyone remuxing containers without re-encoding

## 🔑 Features

| | |
|---|---|
| 🎞️ **mkvmerge remuxing** | Combine video, audio, subtitle and chapter tracks into one MKV without touching the source codecs. |
| ✂️ **Splitting and appending** | Split files by size, duration or chapter markers, then append segments back together. |
| 📦 **mkvextract** | Pull individual tracks, attachments, tags and chapters out of existing MKV files. |
| 🔍 **mkvinfo inspection** | Read container structure, codec parameters and timestamps of any Matroska or WebM file. |
| ✏️ **mkvpropedit** | Edit track flags, names, languages and default settings without a full remux. |
| 📝 **Chapter editor GUI** | Create, import and edit chapter files with a visual timeline aware editor. |
| 🖥️ **Cross format subtitle import** | Accept SRT, ASS, SSA, VobSub and PGS subtitles into a Matroska container. |
| ⚙️ **Command line parity** | Every GUI action maps to a documented CLI flag, useful for batch processing and scripts. |

## 🛠️ Troubleshooting

| Problem | Solution |
|---|---|
| Setup file blocked by SmartScreen | Click **More info**, then **Run anyway** |
| Installer closes immediately | Reboot Windows and rerun the setup file as administrator |
| mkvmerge errors on unsupported codec | Update to the latest build; older releases may not recognize newer AV1 or VVC streams |
| GUI takes long to open with huge MKV | Disable automatic track scanning in Preferences, or work through the CLI tools |
| Subtitle timing drifts after mux | Check source FPS and set the correct default duration per track |
| Output file larger than expected | Verify you are not re-encoding; mkvmerge copies streams, so size should match source |
| Missing audio track after append | Confirm all segments share the same track order and codec parameters |
